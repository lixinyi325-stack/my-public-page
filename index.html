CURATORIAL THREAD

一条给设计师的
观看与拍摄路线

以城市作为展场：西岸观察混凝土、临江立面与公共雕塑；外滩捕捉历史建筑与时尚橱窗；嘉定重点观看安藤、远香湖与校园尺度；再把目光转向玻璃折射、影像叙事与古文明纹样。每一天都有一段可慢走、可拍摄、可消化的空间。

BEFORE YOU GO

出发前确认

  • 周一避开：所有展馆请避开周一；当日开放与展期以官方公告为准。
  • 预约优先：特展使用公众号实名预约；标记为“需预约”的项目不要临时碰运气。
  • 交通重排：Day1–2、Day5–7 地铁优先；Day3 自驾去嘉定并入住，Day4 经上大嘉定校区、宝山返市区。
  • 餐饮策略：日料优先、东南亚备选；热门回转寿司以线上取号为主。

01

METRO · CONTEMPORARY ART

西岸滨江｜当代艺术 + 清水混凝土

NORHOR 西岸店 → 西岸美术馆 → 龙美术馆（西岸馆） → 西岸滨江日落

  • NORHOR 西岸店 到店参观龙文路 317 号星瀚广场 R3 幢；4000㎡三层独栋家居展厅，重点看经典家具、陈列尺度与材质搭配。官方开放时间为 10:00–18:00。
  • 西岸美术馆 需预约蓬皮杜馆藏、计算机艺术、跨媒介装置；观察临江立面与展厅尺度。
  • 龙美术馆（西岸馆） 现场购票旧煤仓伞拱的清水混凝土结构、近现代美术，以及滨江公共雕塑。
  • 西岸滨江 自由拍摄把江边步行留给日落前后，完成材质、尺度与人流关系的观察。
时间 / 预约提醒

NORHOR 西岸店：10:00–18:00，到店参观即可；建议上午先到。
西岸美术馆：公众号实名预约
龙美术馆西岸馆：现场购票，节假日建议提早到。

午餐｜日料优先

首选：徐汇滨江 / 正大乐城一带日式定食或回转寿司，按步行动线挑选。
建议提前取号
次选：泰岛·普吉天堂（保利时光里），团购套餐更友好。

02

METRO · MASTERPIECES & RIVER VIEW

外滩 + 浦东｜大师美术 + 江景建筑

浦东美术馆 → 久事美术馆（外滩 1 号） → 外滩建筑采风

  • 浦东美术馆 需购票莫兰迪大展、镜面长廊、顶楼外滩全景；建议把江景留给收尾时段。
  • 久事美术馆（外滩 1 号） 免费预约百年外滩历史建筑与服饰跨界展；顺路观察万国建筑外立面。
  • 外滩 18 号橱窗 外观拍摄用立面节奏、橱窗叙事和街道反射完成一组商业陈列观察。
预约提醒

浦东美术馆：公众号购票
久事美术馆：免费，公众号预约

午餐｜日料优先

首选：陆家嘴商场内日式定食 / 回转寿司，优先选择可线上排队的门店。
建议提前取号
次选：明泰谷（正大广场）或超级泰（陆家嘴中心），预算更可控。

03

DRIVE · CONCRETE, LAKE & OLD TOWN

嘉定｜建筑群看展 + 园林酒店夜宿

嘉源海美术馆 → 嘉定图书馆 + 保利大剧院 → 禧玥酒店 → 州桥老街

  • 嘉源海美术馆 需预约安藤忠雄清水混凝土、稻田光影、经典座椅 / 家具设计展。
  • 嘉定图书馆 + 保利大剧院 图书馆预约远香湖建筑群；图书馆看“展开书页”屋顶，剧院看混凝土圆筒与水景关系。
  • 州桥老街 自由拍摄傍晚散步；可顺路打卡孔庙 / 嘉定博物馆与法华塔周边街景。
预约提醒

嘉源海美术馆：公众号预约
嘉定图书馆：免费预约；如进入阅览区，请按馆方读者规则办理。

午餐｜日料优先

首选：嘉定城区商场内日式定食 / 回转寿司，选午市套餐。
次选：远香湖周边泰式 / 越南粉，优先团购套餐。
周末建议提前取号

体力机动

如抵达较晚，优先嘉源海与保利大剧院；远香湖完整环湖步行可留给第二天早餐后。

NIGHT 03 · STAY

嘉定禧玥酒店

04

DRIVE · CAMPUS WALK & GLASS / RETURN TO CITY

嘉定返程｜上大校园 + 宝山玻璃光影

禧玥退房 → 上海大学嘉定校区 → 上海玻璃博物馆 → 返回市区

  • 上海大学嘉定校区 外观拍摄联合图书馆、悉尼工商学院教学楼、行健文体中心与林荫道，都适合观察老校区尺度与校园日常光影。
  • 上海玻璃博物馆 需购票玻璃装置、光影迷宫、热力剧场；重点记录透明材质、折射与空间边界。
  • 可选：玻璃 DIY 建议预约若时间充足再安排，为材料感知留一段动手时间；结束后自驾返回市区。
入校 / 预约提醒

上大嘉定校区：校外访客请先核对当日入校与拍摄管理规则，不进入教学或办公限制区域。
玻璃博物馆：公众号购票，周一闭馆。

午餐｜日料优先

首选：嘉定退房后选日式定食，或在宝山商场补给回转寿司。
热门回转寿司建议提前取号
次选：玻璃博物馆周边泰式简餐 / 越南粉，优先午市套餐。

05

METRO · FILM & STREET SCENOGRAPHY

安福路武康路｜影像艺术 + 时尚橱窗

上海电影博物馆 → 安福路 → 武康路 → 徐家汇天主教堂夜景

  • 上海电影博物馆 需预约购票老动画原画、民国戏服、影视手稿；从画面构图与服装细节寻找灵感。
  • 安福路 + 武康路 街区拍摄老洋房、独立买手店与橱窗陈列；适合作为城市材质、色彩和商业陈列采风段。
  • 徐家汇天主教堂（圣依纳爵主教座堂） 傍晚外观拍摄蒲西路 158 号。哥特式双尖顶、清水红砖与玫瑰窗适合蓝调时刻拍摄；从武康路一带搭乘地铁或短程出行前往均顺路。
预约 / 夜间提醒

上海电影博物馆：公众号预约购票。武康大楼以街道外观拍摄为主，避免影响居民生活。
徐家汇天主教堂：夜间安排为外观拍摄；室内游客参观目前为周二至周五 9:00–16:00、15:30 停止入内，若想进堂请另择白天时段并以馆方公告为准。

午餐｜日料优先

首选：合点寿司（美罗城）或徐汇商圈日式定食，地铁衔接方便。
建议提前取号
次选：LEMON GRASS（永新坊）或米泰（安福路）；热门时段建议订位。

06

MUSEUM DAY · PATTERN & CIVILIZATION

人民广场｜古文明纹样主题日

上海博物馆（人民广场馆） → 人民广场建筑群 → 来福士广场

  • 上海博物馆（人民广场馆） 实名预约 / 特展购票“世界树之巅・美洲古文明特展”：玛雅 / 阿兹特克 / 印加金饰、面具、彩陶图腾纹样。
  • 常设展 + 文创商店青铜、玉器、古器物造型纹样；留意纹样如何被转译为文创衍生品。
  • 人民广场建筑群 外观拍摄将上博、上海大剧院和城市规划展示馆放入同一组几何构图中完成收尾。
预约提醒

上博：公众号实名预约；特展单独购票。国庆票紧张，建议提前 3 天锁定。

午餐｜日料优先

首选：人民广场 / 南京东路商圈日式简餐或回转寿司，适合看展后快速补给。
次选：来福士内东南亚餐厅，优先午市套餐；周末建议订位或提前取号。

07

METRO · INDUSTRIAL REUSE & CONTEMPORARY ART

PSA 世博片区｜工业遗产 + 当代艺术

世博会博物馆 → 上海当代艺术博物馆（PSA） → 黄浦江滨水步行 → 可选：中华艺术宫

  • 世博会博物馆 建议预约建议上午先看；以世博建筑、展陈设计和城市叙事为预热，常设展通常免费，特展与影厅以当日票务为准。
  • 上海当代艺术博物馆（PSA） 特展需购票由南市发电厂改造而成，是上海双年展主场馆；重点观察 165 米烟囱、工业桁架、巨型挑空与当代展陈如何共存。常规展免费，收费特展请走官方微信购票。
  • 苗江路滨江 + 世博片区 自由拍摄用工业遗产、江岸尺度和步行人流完成一组“旧生产空间 × 新文化公共性”的街区照片。
  • 可选：中华艺术宫 按当期展览预约 / 购票时间充足再跨江加看；适合补充大型公共文化建筑、色彩与世博遗产的观察。
预约 / 时间提醒

PSA：周二至周日 11:00–19:00，18:00 停止入馆，周一闭馆；常规展免费，特展须购票。
世博会博物馆：建议安排在 PSA 开门前；以官方预约、特展和影厅当日规则为准。
中华艺术宫：周二至周日开放，作为可选项请先核对当期票务。

午餐｜日料优先

首选：世博源商圈内日式定食 / 回转寿司，适合两馆之间快速补给。
热门门店建议提前取号
次选：世博源 / 西藏南路附近泰式、越南粉等东南亚简餐，午市套餐优先。
